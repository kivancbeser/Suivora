# Architecture decision records

Use this directory for accepted or superseded decisions that materially affect architecture, data, security, operations, or long-lived implementation patterns. Open questions remain in `../open-decisions.md` until resolved.

## Suggested format

Name records sequentially, for example `0001-localization-library.md`, and include:

- title and date;
- status (`proposed`, `accepted`, `superseded`);
- context and constraints;
- decision;
- consequences and alternatives considered;
- links to affected source-of-truth documents.

Do not create a decision record merely to restate a confirmed product rule. When a record is accepted or superseded, update related documentation and `../changelog.md`.
